A Collection of Factoring Related Programs/Data
===============================================


Introduction
------------

For now, just a storage place for programs that may be of use to the factoring community.

Community folder
----------------

Just general factoring utilities.


website folder
--------------

Mostly source files for <a href="http://www.cownoise.com" target="_blank">Cownoise</a>

Direct link to web-served javascript apps: <a href="http://www.cownoise.com/extra.html" target="_blank">Extra</a>

Or, just copy the html, css, js files under <a href="https://github.com/JonathanCrombie/Cowcave/tree/main/website/extra">extra</a> to your hard drive and run them for free forever.

(<b>Art</b>: Cherry Blossom animation, <b>Games</b>: Tic-Tac-Toe, Checkers, Flappy Cow, <b>Utils</b>: Basic BigInt Calculator, GCD, LCM, Binary Exp., M-R Primality Test, Cyclotomic Calculator, Aurifeuillean Calculator)
