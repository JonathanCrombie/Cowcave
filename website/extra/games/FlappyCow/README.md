# Cownoise Flappy Cow

A local, dependency-free browser game starring Bessie the flying cow.

## Run it

Open `FlappyCow.html` directly in a modern browser. No install or build step is required.

For the most consistent local browser behavior, you can also serve this folder with any
simple static file server.

## Controls

- Press **Space** or **Arrow Up** to flap.
- Click or tap anywhere in the game to flap.
- Press **P** or **Escape** to pause.

Progress is saved only in the browser's local storage. Each of the five levels uses a
fixed, hand-authored obstacle layout.
